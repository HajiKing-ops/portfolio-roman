PHP authentication system

Individual learning and portfolio project · Not intended for production use.

PHPMariaDBPDOMVCSessionsSecurity

Features and implementation

  • Registration, login, protected profile and logout.
  • Passwords stored with password_hash() and checked with password_verify().
  • PDO prepared queries for database operations.
  • PHP sessions for authentication and profile protection.
  • Escape data displayed in profile with htmlspecialchars().
  • Logging password failures and MariaDB trigger BEFORE INSERT limiting recording to three failures per identifier over one hour.

Known limits

The trigger limits the recording of known failures, but does not block all attempts: unknown identifiers are not tracked, a correct connection remains possible after several failures and no threshold per IP address is applied. A search for an unknown identifier can also trigger a PHP warning. The project does not yet have CSRF tokens, session ID regeneration on login, or explicit configuration of Secure, HttpOnly, and SameSite cookies. Validation of fields and escaping of error messages remain to be completed; Database connection errors may expose technical details, and no automated testing is provided.
